- 기본 마진 ±0.05, 90% CI(z), 양성 대조 규칙은 원고 그대로다. Table S10은 다시 만들지 않았다.

## 1. 결론

1. **재현.** 실행 로그의 L3 분류 1,330건은 실행 당시 계산 방식으로 100% 재현됐고, Table S10 첫 행(145/77/66/68/3/11)은 원고 방식으로 재현됐다. 참조 AUC 95개는 실행 당시 코드의 계산으로 차이 0으로 재현됐다. 현재 공개 코드로는 E2-rate10-early의 5개가 최대 5.9e-4 다르다(5절).
2. **1% 철회에서는 동등성 검정력이 0이다.** 세 1% 시나리오의 모든 실행에서 CI 반폭이 마진보다 커서 통과가 산술적으로 불가능하다. 참 차이가 0이어도, 참조를 20개로 늘려도 통과 확률은 0이다. 원고의 "1%에서는 재학습도 통과하지 못했다"는 관측이 정밀도의 우연이 아니라 설계상 필연임을 뜻한다.
3. **5% 이상에서는 참 차이가 0일 때 통과 확률이 0.54–1.00이다(방법 수준 모형 M2, 참조 5개).** 19개 시나리오 중 15개가 0.80 이상이고, 미달은 1% 셋과 진단 집중(E2-diagMI, 0.54)이다. 참 차이가 마진의 절반(0.025)이면 5% 규모(|X| 840–945)에서 0.37–0.56으로 떨어진다. 이 검정은 "차이가 마진 안"이 아니라 "차이가 0에 가깝다"일 때만 높은 확률로 통과시킨다.
4. **거짓 동등 위험은 무엇을 모수로 보느냐에 따라 다르고, 방법 수준에서는 명목 5%를 넘는 시나리오가 있다.**
   - 감사 대상 모델 하나를 고정하면(M1) 경계(Δ = 0.05)에서 통과 확률은 0.002 이하다. 보수적이다.
   - 방법의 시드 변동을 넣으면(M2, 사전 등록한 주 분석) 통과가 가능한 16개 시나리오에서 0.005–0.114이고, 9개가 명목 수준을 넘는다.
   - 기록 표집 변동까지 넣으면(M3) 0.067–0.150이고 16개 모두 넘는다.
   - 원인은 원고가 이미 밝힌 대로 CI가 대상 모델의 학습 변동을 빼고 있기 때문이다. 규칙이 쓰는 표준오차는 실제 변동의 0.64–0.95배다(표 A6).
5. **양성 대조는 마진 크기에 가까운 잔여만 잡는다.** 80% 확률로 검출되는 최소 잔여는 5–20% 규모에서 0.037–0.051 AUC, 1%에서 0.076–0.086이다. 관측된 P1 잔여(후기 0.03–0.10, 중기 0.01–0.02, 초기 ≈ 0)에 모형을 적용한 예측 검출 확률은 관측 빈도와 맞는다(표 A3). 중기·초기 철회에서 대조가 실패한 것은 잔여가 검출 한계 아래였기 때문이다.
6. **참조 수를 늘려도 한계는 그대로다.** 참조 5개에서 20개로 늘리면 Δ = 0의 통과 확률은 조금 오르지만(예: E2-mid 0.82 → 0.88), 경계에서의 통과 확률은 줄지 않고 1% 조건은 0에 머문다(표 A2). 빠진 것은 참조의 수가 아니라 대상 쪽 변동이다.
7. **보고된 분류는 참조 선택에 대해 대체로 안정적이나, 근사 방법의 통과는 덜 안정적이다.** U0 모델 10개에서 참조 5개를 고르는 모든 경우를 열거하면 보고된 분류가 92.5–96.9%에서 유지된다. 실행 단위로는 U4의 통과 3건 중 0건, U4s의 통과 11건 중 6건만 90% 이상 유지됐다(표 A5).
8. **모형 적합.** Δ = 0이 구성상 참인 U0 실행에서 모형이 예측한 통과 수는 143.6(95% 예측 구간 134–152)이고 관측은 145다. 시나리오별로도 19개 모두 예측 구간 안이다. 모의 곡선은 이 범위에서 쓸 수 있다.

원고의 기존 서술과 충돌하는 결과는 없다. 2·4·5번은 원고가 정성적으로 밝힌 한계(보충 S4 "Statistical design", 본문 Limitations)를 수치로 뒷받침하며, 4번의 M2·M3 값은 원고에 없는 불리한 수치다.

## 2. 방법 요약

- 규칙(원고 그대로): d = 대상 AUC − 참조 평균, se = sqrt(se_boot² + s²/n), 90% CI = d ± 1.645·se. 통과 ⇔ CI ⊂ (−0.05, 0.05), 기준 초과 ⇔ 통과가 아니고 하한 > 0, 그 외 판정 불가.
- 모의 모형: 참조 n개 ~ N(μ, σ_ref²), 대상 = μ + Δ + N(0, σ_T²). σ_ref는 시나리오의 U0 모델 10개 표준편차, se_boot는 U0 실행 10개의 평균. 칸마다 100,000회, 시드 20261109.
  - M1: σ_T = 0(감사 대상 모델 고정).
  - M2(주 분석): σ_T = σ_ref(재학습과 같은 학습 변동을 가진 방법).
  - M3: M2에 기록 표집 변동 σ_rec,d(A2의 대응 부트스트랩)를 더함.
- 부트스트랩 반복값은 독립 시드로 쓰지 않았다. se_boot는 규칙의 CI 폭 성분으로만 들어가고, A2의 대응 부트스트랩은 기록 표집 변동의 크기를 재는 데만 썼다.
- 그림: `results/fig_l3_power.pdf`. (a) 후기 철회 1/5/10/20%의 Δ별 통과·기준 초과 확률(선 = 모의), (b) 양성 대조 검출 곡선(선 = 모의)과 시나리오 19개의 관측 빈도(표식).

## 4. Table S10과의 관계

- Table S10은 마진(0.05, 0.025)과 분위수(z, t)를 바꿨을 때 190개 실행의 통과 수가 어떻게 달라지는지를 보인다(판정이 설정에 민감하다는 관측).
- 이 분석은 설정을 기본값에 고정하고, 참 차이 Δ에 따른 판정 확률을 보인다(그 규칙의 작동 특성). Table S10을 대체하지 않고 설명을 보탠다: t 분위수에서 U0 통과가 145 → 122로 줄어드는 것은, z 분위수와 참조 4–5개의 표본 표준편차로 만든 구간이 방법 수준 변동을 덜 담기 때문이라는 표 A1·A6의 결과와 같은 방향이다.

## 5. 재현에서 찾은 것

- **자기 참조.** 실행 로그의 U0 L3 필드는 자기 자신을 참조에 넣고 계산돼 있다(로그 기준 U0 통과 146, 원고 기준 145). 원고 수치는 집계 단계에서 자기 참조를 뺀 값이라 맞다. 실험 C가 같은 사실을 독립으로 확인했고, 보충 Table S8의 "실행 로그와 다른 곳"에 이 차이가 빠져 있다.
- **NaN 점수 기록 하나.** E2-rate10-early에서 철회 기록 하나가 그림자 모델 16개 모두의 구성원이어서 OUT 평균이 없다. 실행 당시 코드에는 방지 코드가 없어 그 기록의 점수가 NaN이 되어 최고 순위로 계산됐다. 그 시나리오의 저장된 AUC는 모든 모델에서 최대 1/|X| = 5.9e-4만큼 높다. 대상과 참조에 같은 방향으로 들어가므로 차이 d와 분류에는 사실상 영향이 없지만(참조 5개의 이동 폭 2.1e-4–5.9e-4), 현재 공개 코드로 그 시나리오의 AUC는 비트 단위로 재현되지 않는다. `fl/exp_lira.py`의 주석 "최종 재실행에서는 발생하지 않았다"와 11-01 코드 검토 보고의 해당 항목은 사실과 다르다.

## 6. 통계적 한계

- 시나리오당 U0 모델이 10개라 σ_ref의 90% 구간이 추정값의 0.73–1.65배다. σ_ref를 그 상한으로 두면 Δ = 0의 통과 확률이 내려가고 경계의 통과 확률이 올라간다(`a1_simulated.json`의 `M2_sref_hi`).
- 정규성은 표준화한 U0 AUC 190개에서 기각되지 않았으나(Shapiro–Wilk p = 0.25), 시나리오 안의 10개로는 검정력이 낮다.
- 대상 모델(P1, U1–U4)의 기록별 점수가 없어 M3의 기록 표집 변동은 참조 모델끼리의 값으로 대신했다. 대상 모델의 체크포인트는 실행 뒤 삭제됐고, 결정적 재생성(A3)은 하지 않았다.
- 시나리오의 10개 실행은 참조 집합과 X·Z·그림자 모델을 공유한다. 통과 수의 분산은 이항 분포보다 크다(표 A7).
- 통과가 산술적으로 가능해지는 최소 규모(|X| = |Z| ≈ 181, 참조 오차 0 가정)는 Hanley–McNeil 근사에 의한 외삽이다.
- 그림자 모델 16개의 표집 변동은 AUC에 0.003–0.014, 차이 d에 0.001–0.007이다(표 A6). 규칙의 표준오차에는 들어 있지 않다.
