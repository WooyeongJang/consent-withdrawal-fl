# Challenge 2021 진단 코드 사상표 (3장 8.1 "사상표는 학습 개시 전에 커밋")

- `dx_mapping_scored.csv`, `dx_mapping_unscored.csv`: PhysioNet/CinC Challenge 2021 평가 저장소(physionetchallenges/evaluation-2021, main)의 SNOMED CT 코드표(2026-10-26 수령, SHA-256은 아래). 공개 저장소에는 싣지 않는다(2026-10-31 결정). `scripts/fetch_c2021_maps.sh`가 같은 파일을 고정 커밋 e3a9eb4에서 받아 해시로 검증한다.
- `mapping_superclass_v0.csv`: 다섯 코호트(ningbo, georgia, chapman_shaoxing, cpsc_2018, cpsc_2018_extra)에 나오는 코드 118개를 PTB-XL 진단 상위 범주(NORM/MI/STTC/CD/HYP)로 사상한 **초안**.

원칙(초안 A, 보수적): PTB-XL `scp_statements.csv`에서 **진단(diagnostic) 문장**에 해당하는 코드만 상위 범주에 넣는다. 형태(form) 문장(ST 하강·상승, T파 이상·역위, Q파 이상, 전압 기준 LVH 등)과 리듬 문장은 넣지 않는다.
NORM은 Challenge에 "정상 심전도" 코드가 없으므로 "NSR(426783006) 외 다른 코드가 전혀 없는 기록"으로 정의한다.
상위 범주가 하나도 없는 기록은 PTB-XL의 레이블 없는 기록(411건)과 같이 학습에서 제외한다.

대안(초안 B, 포괄적): 형태 문장 STD·STE·TAb·TInv·STIAb → STTC, QAb → MI, LVHV → HYP. 코호트 간 레이블 관행 차이(3장 반영 14번)를 줄이지만 PTB-XL 상위 범주의 정의와 달라진다.

**상태: 초안 B 채택(3장 반영 41번, 2026-10-27 사용자 결정).** 학습에 쓰는 사상표는 `mapping_superclass_v1.csv`(초안 B)다. `mapping_superclass_v0.csv`(초안 A)는 비교용으로 남긴다. `fl/prepare_c2021.py`는 v1로 `meta.csv`를, v0으로 `meta_A.csv`(비교용)를 만든다.

관찰:
- **초안 A에서는 범주가 사실상 없는 기관이 생긴다.** georgia의 MI는 7건(학습 fold에서는 약 5–6건), chapman의 HYP는 21건이다.
  - "각 기관의 학습 집합에 다섯 범주가 모두 있어야 한다"(8.1, PTB-XL 기준)를 보조 데이터에 똑같이 적용하면, 형식적으로는 충족하지만 실질적으로는 충족하지 못한다.
- **초안 B에서는 모든 기관·범주가 225건 이상이다.** 레이블 있는 기록의 비율도 35–79%에서 54–84%로 늘어, 제외되는 기록이 준다.
- **어느 초안이든 코호트 간 차이가 크다**(예: CD 11.7–30.7%, HYP 2.2–21.4%). 이는 레이블 관행 차이(3장 반영 14번)와 같은 문제다. 보조 실험의 성능을 주 데이터와 직접 비교하지 않는다.
